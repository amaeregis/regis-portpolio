In creating my portfolio, I applied different UI/UX principles to make it look simple, organized, and easy to navigate. I made sure the design was clean and that users could find what they need without getting confused. I used consistent colors, fonts, and spacing so the whole site would look neat and balanced. I also worked on making it responsive, meaning it still looks good whether you open it on a phone or computer.
One of the challenges I faced was deciding how to arrange each section on the page. At first, I added too much information, which made it look messy. I solved this by simplifying my layout and using sections to separate the content. Another challenge was making the site mobile-friendly. I learned how to use CSS media queries to adjust the layout for smaller screens, and that helped a lot.
If I were to improve my portfolio, I would like to add more animations or hover effects to make it more interactive. I also want to add a short blog or project details page where I can explain what I learned from each project. Lastly, I might include a feedback form or visitor counter to know how many people have seen my site.
